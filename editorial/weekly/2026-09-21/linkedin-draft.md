GitHub Actions workflow execution protections just went GA. 🔒

Actor rules, event rules, workflow-file targeting, an enterprise insights
view, and a REST API to manage it all as code, plus new secure defaults
that directly address the "Pwn Request" class of pull_request_target
vulnerabilities.

If you're running GitHub Enterprise at scale, this is one of the more
practical governance upgrades of the month: you can now scope execution
policy to individual workflow files instead of whole repositories, audit
impact before enforcing, and codify the whole thing.

Full breakdown and a rollout plan (evaluate mode → insights → enforce →
policy-as-code) coming soon on the blog.
