# LinkedIn Teaser (Unpublished Draft)

GitHub just closed one of the biggest objections enterprises raise about agentic Copilot: "what stops a developer from approving something risky?"

As of 9 September 2026, GitHub Copilot Business and Enterprise admins can set centrally managed permissions for agent operations, shell commands, file access, and network domains, that can be blocked, gated behind human approval, or auto-allowed. The key detail: these policies can't be weakened by user settings, workspace settings, or saved approvals. Enforcement, not suggestion.

It shipped alongside two other hardening moves in the same week: least-privilege cache access for GitHub Actions (`cache-mode`) and a new ruleset that blocks pull requests introducing exposed secrets from merging.

If your organisation has been waiting for stronger admin controls before expanding Copilot agent mode, this is worth a look.
