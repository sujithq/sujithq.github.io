Microsoft FORGE Lab reported memory-safety bugs in Rust's core and std libraries, including cases where safe Rust code can lead to undefined behavior. The findings were made using Hyenas, FORGE's research version of codename MDASH, and focused on three patterns of misplaced trust in unsafe code.
