Azure SQL Database public preview adds database-level managed identity support, including federated identity credentials (FIC), for creating database scoped credentials in T-SQL. This lets each database use a user-assigned managed identity to access Azure Blob Storage and Azure Data Lake Storage Gen2 via external tables and OPENROWSET.
