SQL Server on Linux now supports the bulkadmin fixed server role and the ADMINISTER BULK OPERATIONS permission starting with SQL Server 2025 CU9 and SQL Server 2022 CU27. This enables bulk data import operations without requiring users to be members of the sysadmin role.
