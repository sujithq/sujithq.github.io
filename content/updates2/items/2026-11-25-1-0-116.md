Release 1.0.116 adds several CLI and editor integration fixes, including MCP/server startup and auth handling, sandbox and permissions behavior, session and model workflow improvements, and multiple terminal/UI accessibility corrections. It also includes changes for extension manifests, workspace MCP config parsing, search and diff edge cases, and memory growth reduction in long sessions.
