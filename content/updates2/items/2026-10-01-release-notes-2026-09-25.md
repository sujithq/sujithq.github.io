AKS release v20260925 adds GA identity bindings, preview support for Ubuntu 26.04 and Windows Server 2022 to 2025 OS SKU migration, and includes multiple behavioral changes, bug fixes, and component updates across Kubernetes versions. It also announces upcoming VMAS cluster auto-migration to VM node pools starting 2026-09-30 and notes that Windows Server 2022 is unsupported on Kubernetes 1.37+.
