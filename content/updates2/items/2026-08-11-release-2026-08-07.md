AKS release v20260807 adds Node Auto Provisioning support for restricted publicNetworkAccess clusters, global automatic availability zone placement, control-plane-only upgrades to AKS LTS, and GA node pool rollback. It also includes several behavioral changes that can trigger immediate node reimages on Kubernetes 1.37+, plus component and image updates.
