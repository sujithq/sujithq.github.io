Release v1.0.101 adds several CLI and MCP workflow fixes, including native structured output for dynamic workflow subagents on supported models, new assisted approval instructions, and more reliable sign-in and permission handling. It also fixes model selection, session resume/startup behavior, Windows/macOS shell command issues, and multiple provider-specific request and image-limit problems.

- **Source:** [GitHub Copilot CLI releases](https://github.com/github/copilot-cli/releases/tag/v1.0.101)
